# Aprender+ API

API educacional do projeto Aprender+, alinhada ao ODS 4 — Educação de Qualidade.

## Tecnologias

- Node.js
- Express
- Prisma
- SQLite
- JWT
- bcryptjs
- Zod
- Swagger/OpenAPI
- Jest
- Supertest
- Postman

## Objetivo

Disponibilizar uma API educacional para gerenciamento de usuários, conteúdos, atividades e acompanhamento do progresso dos alunos.
